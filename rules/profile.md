# 我的页面（资产、心愿、生活概览）

目前只做了浏览器原型；Android 移植时按 `model.js` 里的同名纯函数和单测口径实现。

## 布局

- 自上而下：身份卡 → 净资产卡 → 心愿 → 生活概览 2×2 → 设置分组 → 隐私小字 → 版本注记。设置下沉，不再放在页首。
- 设置行的 id（`backup-button`、`permissions-button`、`preferences-button`、`automation-button`）不要改，其他检查依赖它们。

## 资产口径

- 资产按账户记录余额快照（`{ accountId, date, amount, note }`），不逐笔记账。负债也存正数，汇总时计为负值（`ASSET_KINDS` 里 `liability: true`）。
- 某个时点的余额 = 该时点及以前最近的一次快照；同一天有多条时取数组里靠后的那条。账户在那个时点前还没有快照，就不计入。
- 「本月变化」对比上月月末净值；上月月末前一条快照都没有时显示「本月暂无对比」，百分比为 null。
- 走势图取近 6 个月：过去各月取月末，本月取今天。当月有带备注的快照时，这个点画成实心。
- 金额 0 到 100 亿，最多两位小数；日期不能晚于今天；备注不超过 40 字，可以为空。
- 「更新余额」只给改动过的账户生成快照；什么都没改就直接关闭，不提示。
- 「隐藏金额」只影响显示，所有金额显示为 `¥ ••••`，屏幕阅读器读到的走势说明也会省掉金额。

## 心愿

- 心愿最多 3 个（未归档的），进度只看所关联资产账户的最新余额，不能关联负债账户。
- 每月还需 = 剩余金额 ÷ 剩余月数（不足 30 天按 1 个月，向上取整）；过了截止日期显示「已过截止日期」，不再计算每月还需。
- 删除账户时，关联的心愿一并移除，删除前的确认文案要写明这一点。

## 生活概览

- 专注取本周 `focusSummary`；待办取本月完成数，点进去切到「已完成」；日记连续天数由 `diaryStreak` 计算（今天没写就从昨天往前数，回收站里的不算）；用屏取今日示例 `usageDaySummary`。
- 原型数据仅在内存，刷新后恢复示例。资产数据不能描述为已经接入银行或真实账户。
